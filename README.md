# toshiksoni.github.io

Developer site for Toshik Soni's Android apps, served by GitHub Pages.

- `app-ads.txt` — AdMob publisher declaration. Must stay at the site root.
- `japa/` — Japa: about page, `privacy/`, `support/`, `feedback/`.

Plain HTML and one stylesheet (`assets/site.css`); `.nojekyll` turns off Jekyll.
